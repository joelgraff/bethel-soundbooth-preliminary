🎚️ Soundbooth Operator Portal

Local only — for church sound & presentation volunteers.

Start here: the Control Dashboard

For day-to-day operation (health at a glance, restart a stuck service, start/stop the livestream, check HDMI previews, set the Sunday auto-start time, record the board), use the web dashboard — it's built for this and needs no terminal.

  • At the booth: already open — switch to it with Super+Page_Down (or Super+Alt+2).
  • From another device on the soundbooth Wi-Fi: open http://<booth PC's address>:8420/ and enter the PIN.

The rest of this page and content/quick-reference.md are the terminal/command fallback — for when the dashboard itself is down, or for anything it doesn't cover yet.

Golden Rule

Any app that produces audio goes to the Presonus 32SX board.

Exception: the program feed (sanctuary TV + livestream) goes to the HDMI TV instead of the board (deliberate). Manual VLC playback is fine but is not part of that path.

Quick Checks

  • Health banner red or yellow on the dashboard? Read the message there first — most issues say exactly what to do.
  • Spotify or browser playing? It should be audible on FOH / visible on the board.
  • Use ~/bin/ensure-audio-routes.sh if something is missing (or the dashboard's "Restart Audio Routing" quick action).
  • Open qpwgraph to see the graph.
