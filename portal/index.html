🎚️ Soundbooth Operator Portal

Local only — for church sound & presentation volunteers.

Golden Rule

Any app that produces audio goes to the Presonus 32SX board.

Exception: VLC is sent to the HDMI TVs (deliberate).

Quick Checks

  • Spotify or browser playing? It should be audible on FOH / visible on the board.
  • Use ~/bin/ensure-audio-routes.sh if something is missing.
  • Open qpwgraph to see the graph.

Key Files (in soundbooth-project/)

  • audio-routing/ — rules and scripts for automatic routing
  • replicability/ — how to rebuild everything from a fresh Ubuntu install
  • portal/content/ — source for this portal and more docs
