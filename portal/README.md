# Portal / Wiki

Local-only documentation for staff and volunteers who are not power users.

Primary implementation: single-file TiddlyWiki (easy browser editing) or static self-contained HTML.

All source content lives in `content/`.

## Serving
- Direct file:// open is fine.
- Optional local-only http server in `serve/`.
